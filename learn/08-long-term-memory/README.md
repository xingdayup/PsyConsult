# 08 长期记忆：临床要点提取

> 学习目标：长期记忆的完整生命周期——提取什么、何时提取、怎么去重、怎么被用回来。
> 状态：骨架已含全部要点与代码锚点，叙述性文字待补。

## 1. 定位

会话状态（第 05 章）回答"这次对话聊了什么"；长期记忆回答"**这个患者/医生是谁**"——主诉、诊断结论、用药方案、量表分数、复诊周期。**跨会话**生效：新会话首轮即注入。

## 2. 生命周期

```
第 5/10/15... 轮（后台任务，不阻塞 SSE）
  → 从 checkpoint 读会话历史 (aget_state)
  → 渲染为 role: content 文本
  → LLM 提取（"类别: 内容"格式，中文）
  → 与已有记忆子串去重
  → 向量化存入 Milvus long_term_memory
下一轮任意会话
  → 用户提问向量化 → COSINE 检索 top-5 → 注入 memory_context
```

## 3. 关键实现

- **提取提示词**（`preference_extractor.py`）：只提取"具体的、可操作的临床信息"，示例锚定格式：`主诉: ...`、`诊断: 中度抑郁发作 (ICD-11: 6A70)`、`用药: 舍曲林 50mg qd`、`PHQ-9: 14 分`；无信息输出"无"
- **去重**：新条目与已有记忆做子串包含判断（`item in ex or ex in item`）——完全重复能挡住，"舍曲林 50mg" vs "100mg" 会共存（已知局限，见下）
- **触发**（`chat_service.py`）：进程内按 (user_id, session_id) 计数，每 5 轮 `asyncio.create_task` 后台执行；任务放入集合持有强引用（防 GC 中断）
- **存储**：Milvus `long_term_memory` 集合，IVF_FLAT + COSINE，`user_id` 标量过滤隔离

## 5. 已知局限（面试主动讲比被问出来好）

- **只增不删**：用药方案调整后新旧两条共存，可能注入过期信息（临床风险点，改进方向：按类别 upsert 或加时间戳衰减）
- **子串去重粗糙**：挡不住矛盾条目
- **无 TTL**：临床信息永久存储，合规上应加保留策略 + 明确不入真实患者数据

## 面试官可能追问

1. 为什么每 5 轮而不是每轮提取？（成本/延迟/收益平衡；每轮浪费且重复内容多）
2. 提取失败会影响对话吗？（不会：后台任务 + 全链 try/except，记忆是增强不是依赖）
3. 患者隐私怎么处理？（原型约束：不入真实数据；生产化需要脱敏 + 保留策略 + 审计）
