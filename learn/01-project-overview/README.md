# 01 项目总览

> 学习目标：10 分钟讲清楚这个项目是做什么的、整体长什么样、能力边界在哪。

## 1. 场景与问题

精神科临床工作中，医生面对的核心决策有三类：

1. **鉴别诊断**：患者主诉"近两周情绪低落、失眠" → 对照 ICD-11 标准判断是抑郁发作还是双相抑郁相
2. **治疗推荐**：确诊后 → 检索中国精神科防治指南，给出一线/二线方案与剂量
3. **药物审查**：开处方前 → 检查药物组合的相互作用风险（如 SSRI + MAOI 的 5-HT 综合征）

PsyConsult 把这三类决策做成**多智能体流水线**，用自然语言进、结构化诊疗建议出，并且支持**多轮追问**（"这位患者的一线用药是什么"能接住上一轮的病例）。

## 2. 能力边界（面试必问，先自己想清楚）

**能做的**：
- 基于输入病例做多智能体推理，输出带证据引用的鉴别诊断（逐条对照 ICD-11，✅/❌/⚠ 标记）
- 流式输出（SSE），每个节点的进度实时推送前端
- 跨轮次记住病例（Checkpoint）、跨会话记住患者临床要点（Milvus 长期记忆）
- 高频问题直接命中语义缓存（实测 0.27s vs 全流程约 60s）

**不能做 / 原型限制**：
- 输出仅供临床参考，不构成诊疗依据（免责边界）
- 知识库规模小（16 种药物、27 对相互作用的图谱 + 少量指南文档）
- 图谱 Text2Cypher 默认关闭（关键词检索为主，见第 07 章）
- 无真实 EHR 集成，输入是医生手打的病例描述

## 4. 三个"记忆"不要混淆（初学者最容易乱）

| 名称 | 存哪 | 存什么 | 生命周期 |
|------|------|--------|---------|
| **会话状态** | Redis（LangGraph Checkpoint） | 完整消息历史、各节点结论 | 24h TTL，读时续期 |
| **长期记忆** | Milvus `long_term_memory` | 提取后的临床要点（主诉/诊断/用药/量表分） | 永久，跨会话 |
| **语义缓存** | Milvus `qa_semantic_cache` | 问题-答案对 | 永久，自填充 |

一句话区分：会话状态管"这次对话聊了什么"，长期记忆管"这个患者是谁"，语义缓存管"这个问题是不是问过了"。
